# صيّاد الميمكوين — نسخة تجريبية عربية

## ما الذي يفعله؟
- يجلب ملفات العملات الحديثة عبر واجهة DexScreener العامة، ثم يحاول العثور على أزواج Solana.
- يعرض السعر والسيولة وحجم التداول والتغير والعمر ودرجة تقييم تقريبية.
- يطبق محاكاة شراء/بيع افتراضية حسب إعدادات محددة.
- يعرض الرصيد الافتراضي والصفقات المفتوحة وسجل العمليات.

## حدود مهمة
- هذه نسخة أولية تعليمية؛ لا تستخدم محفظة ولا تنفذ معاملات على البلوكشين.
- درجة التقييم قواعد بسيطة وليست ذكاء اصطناعيًا تنبؤيًا ولا فحصًا أمنيًا كاملًا.
- البيانات قد تكون ناقصة، وقد لا تظهر العملات التي لم تنشئ زوج تداول بعد.
- بيانات الحساب محفوظة في ذاكرة الخادم فقط، ويمكن أن تختفي عند إعادة التشغيل.
- لا تعتمد على نتائج المحاكاة لاتخاذ قرار استثماري.

## التشغيل محليًا
1. ثبّت Python 3.11 أو أحدث.
2. نفّذ: `pip install -r requirements.txt`
3. نفّذ: `python app.py`
4. افتح: `http://127.0.0.1:10000`

## النشر المجاني على Render من الهاتف
1. أنشئ حسابًا على GitHub ثم مستودعًا عامًا جديدًا.
2. ارفع كل الملفات والمجلد `templates` مع الملف `templates/index.html`.
3. افتح https://render.com ثم أنشئ Web Service واربط مستودع GitHub.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
6. اختر الخطة Free ثم Deploy.
7. افتح رابط `onrender.com` الذي ينشئه Render.

## ملاحظة عن Render المجاني
الخدمة قد تتوقف بعد فترة عدم نشاط، وقد يعاد تشغيلها وتُمسح بيانات الذاكرة. لذلك لا تعتبرها بوتًا يعمل 24/7.
